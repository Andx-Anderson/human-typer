# Human Typer

Types text into whatever window is focused, like a person would.

## How it works

1. Paste your text into the app.
2. Click Start, then click into the window you want it typed in.
3. It types at a random speed in your WPM range, pauses at punctuation, makes typos, and fixes them with backspace.

**F8** pauses. **Esc** stops.

For code, pick your editor (VS Code, IntelliJ, Plain, or Auto). It then works with the editor's auto brackets and auto indent instead of typing over them.

## Run it

```
pip install -r requirements.txt
```

Then double-click `Human Typer.bat`.
